# My-rpg-game

一个纯文字回合制 RPG 小游戏，使用 Python 编写，无需任何第三方依赖。

## 游戏简介

勇者在黑暗森林中与凶残的**暗影魔兽**展开生死决斗！  
游戏采用回合制战斗，玩家通过键盘输入数字选择行动。

## 如何运行

确保已安装 **Python 3.10+**，然后执行：

```bash
python game.py
```

## 角色属性

| 角色 | 生命值 (HP) | 蓝量 (MP) |
|------|------------|----------|
| 勇者 | 120 | 80 |
| 暗影魔兽 | 160 | 60 |

## 勇者技能

| 编号 | 技能名称 | MP 消耗 | 效果 |
|------|---------|--------|------|
| 1 | ⚔ 普通攻击 | 0 | 基础物理攻击，伤害 18–28 |
| 2 | 🔥 烈焰冲击 | 20 | 强力火焰攻击，伤害 35–50 |
| 3 | ❄ 冰霜箭 | 15 | 伤害 22–36，并冻结怪兽一回合 |
| 4 | 💚 治愈术 | 25 | 恢复自身生命值 32–48 |

## 战斗机制

- **回合制**：勇者先行动，然后怪兽行动
- **蓝量限制**：技能需要足够的 MP 才能释放，MP 不足时无法使用
- **冻结状态**：冰霜箭命中后，怪兽下一回合跳过行动
- **狂暴状态**：怪兽血量低于 30% 时进入狂暴，伤害提升 20%
- **蓝量恢复**：勇者每回合结束后恢复 3 MP（冥想效果）
- **逃跑**：输入 `0` 可选择逃跑，结束本局游戏
